# Amazon Bestseller Books Analysis

An interactive Streamlit dashboard for analyzing Amazon's Top 500 Bestselling Books dataset.

## Features

- Dataset Overview
- Category Analysis
- Author Insights
- Price Analysis
- Rating Analysis
- Most Reviewed Books

## Tech Stack

- Python
- Pandas
- Streamlit
- Plotly

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Dataset

Amazon Top 500 Bestselling Books Dataset
